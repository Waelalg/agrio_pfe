# State of the Art Selected Papers

This note records the papers used for the State of the Art chapters and the papers excluded from the main review. Main papers were selected only when they proposed, implemented, simulated, evaluated, or validated a concrete system, model, architecture, prototype, algorithm, or case study.

Figures were inserted only when a downloaded image matched the corresponding chapter/subsection number and compiled correctly with XeLaTeX. Subsections without a matching compile-safe image were left without a figure.
