\chapter{Missing Visual Capture Guide}

\begin{itemize}

\item Open the forecast page and capture the full weather-aware workspace.

\item Open the schedules page and capture the event list and create/edit form.

\item Open the validated decisions page and capture validated recommendations.

\item Capture the Flutter mobile dashboard and zone/twin state screens.

\item Run docker ps or open Docker Desktop and capture running containers.

\item Open the ML service /health endpoint and capture the JSON response.

\item Open the ML service /metadata endpoint and capture model features and metrics.

\item Call /predict using Swagger or Postman and capture the prediction output.

\item Send ON\_D5 and capture MQTT command plus WeMos D5 ON status.

\item Send OFF\_D5 and capture MQTT command plus WeMos D5 OFF status.

\end{itemize}
